# 🐉 Dragon Island — Master Game Design & Technical Document

This project is a casual, child-friendly 2D top-down game inspired by *Stardew Valley* and *Dragon City*. It is designed to be rebuildable in any modern game engine (such as Unity, Godot, or Unreal).

To make these specifications digestible for developers and AI agents, the documentation has been split into modular files. Please refer to the specific documents below for implementation details:

---
